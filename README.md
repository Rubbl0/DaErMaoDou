# 大耳帽兜桌宠

一个运行在 Windows 桌面上的可爱像素风桌面宠物。它会在桌面上随机走动、眨眼、困倦、回应鼠标操作，并提供待办清单和健康提醒等功能。

## 快速开始

1. 将整个项目文件夹解压到任意位置。
2. 不要单独移动或删除 `_internal`、`assets`、`sounds` 文件夹。
3. 双击 `大耳帽兜桌宠.exe` 启动。

这是 PyInstaller 打包的 Windows 便携版，不需要另外安装 Python。建议将整个文件夹一起保存或移动。

## 主要功能

- 随机待机：自动走动、眨眼、左右观察和开心弹跳。
- 鼠标互动：点击、长按、拖动、摸头，以及连续点击反馈。
- 拖动眩晕：长时间拖动后松手，会出现眩晕和星星效果。
- 跟随鼠标：在设置中开启后，桌宠会跑向鼠标；够到鼠标会开心，在上方跳跃尝试够到，够不到时会生气。
- 自动睡眠：长时间无操作后进入睡眠，操作鼠标或键盘可唤醒。
- 待办清单：添加任务、选择日期和时间、完成任务并查看划线记录。
- 到点提醒：当天待办到时间后会开心并弹出提示气泡。
- 迷你待办：可在桌宠右上角显示未完成任务。
- 健康提醒：可选开启喝水和久坐提醒。
- 音效：点击、摸头、拖动、眩晕和完成待办等操作有对应音效。
- 设置面板：可调整随机走动、音效、睡眠、跟随鼠标、置顶、自启动等选项。
- 粉色可爱界面：右键菜单和设置窗口采用统一的粉色卡片风格。

## 常用操作

| 操作 | 作用 |
| --- | --- |
| 左键点击 | 触发表情和点击反馈 |
| 左键拖动 | 拖动桌宠；长时间拖动后会眩晕 |
| 鼠标移动到头顶并停留 | 触发摸头反馈 |
| 右键点击 | 打开功能菜单 |
| 右键菜单中的“设置” | 修改功能开关 |
| 右键菜单中的“待办” | 打开待办清单 |
| 右键菜单中的“说明” | 查看完整操作说明 |

## 数据文件

- `settings.json`：保存功能开关和窗口设置。
- `todos.json`：保存待办任务。

删除这两个文件后重新启动，程序会自动创建默认配置。请注意，这会清除本地设置或待办记录。

## 目录说明

- `大耳帽兜桌宠.exe`：程序入口。
- `assets/`：角色图片素材。
- `sounds/`：音效素材。
- `_internal/`：程序运行所需的打包依赖，请勿删除。

## 系统要求

- Windows 10/11，64 位。
- 建议使用 1920×1080 或更高分辨率，并允许桌面应用播放声音。
